dsh-qwen-paint

面向 DeepSeek Harness (DSH) 的本地图像 / 视频 / 语音生成与编辑插件 · (绘图)千问（优化版）

版本 0.3.1 MIT Windows / Linux NVIDIA / Intel Arc / AMD / 核显 8 GB 低内存档位 中文
重要边界：本插件是运行在用户本机的 DSH bundle（按本地目录安装）， 不是 Web 服务。本站是纯静态文档页，没有 HTTP API、没有 OpenAPI 规范、 没有 MCP server，也不收集或转发任何用户数据。因此本站不声明 ai-plugin.json / OpenAPI / MCP 等 manifest —— 那是会误导 Agent 的虚假信号。

经由本机 ComfyUI 调用 Qwen-Image 2.1 / 官方 Turbo 模型， 在对话中完成文生图、多参考图编辑、局部重绘、元素移除与四向扩图；结果落盘并在会话界面内直接呈现。

能做什么

能力工具说明

怎么安装

本包已发布到 npm（dsh-qwen-paint，当前 0.3.1），可直接按包名安装；开发调试时也可用本地目录形式：

dsh plugin --profile desktop add dsh-qwen-paint
# 或：dsh plugin --profile desktop add link:<本插件目录的绝对路径>
  • 使用 desktop profile 前，需先完全退出 DSH。
  • 兼容 DSH >= 0.2.0-rc.2、Node.js >= 18.0.0。
  • 无构建步骤：lib/ 即最终运行代码，dsh.build.strategy = none。
  • 完整步骤、profile 选择与排错见 INSTALL.md。

网络边界

出图数据（提示词与图片）只发往本机 127.0.0.1 / localhost / ::1 的 ComfyUI。

  • 由 lib/net-guard.js 在代码层强制，不是仅靠文档约定。
  • 无需任何 API 密钥，不产生调用费用。
  • 本站为 GitHub Pages 静态托管：无后端、无表单、无登录、无第三方统计脚本。
